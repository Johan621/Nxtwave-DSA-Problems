Stable Battery
You are given an integer num, which represents the starting battery level of a device.
The device follows a special charging cycle where the battery level is repeatedly updated. In each cycle, the new battery level is calculated by summing the squares of the digits of the current battery level.
Your task is to determine whether the device will eventually reach a stable state where the battery level becomes 1 or if it will enter an infinite loop without reaching 1.
A stable state is defined as the device reaching a battery level of 1. If the device falls into a cycle (where the battery level keeps repeating without reaching 1), it will never reach a stable state.
Return true if the device will eventually reach a battery level of 1. Otherwise, return false if the device will enter an infinite loop and never reach 1.

Example 1
Input:
num = 19
Output:
true
Explanation:
Starting from 19, the following transformations occur:
19 → 1² + 9² = 1 + 81 = 82  82 → 8² + 2² = 64 + 4 = 68  68 → 6² + 8² = 36 + 64 = 100  100 → 1² + 0² + 0² = 1  
The device reaches a stable state at 1, so the answer is true.

Example 2
Input:
num = 4
Output:
false
Explanation:
Starting from 4, the following transformations occur:
4 → 4² = 16  16 → 1² + 6² = 1 + 36 = 37  37 → 3² + 7² = 9 + 49 = 58  58 → 5² + 8² = 25 + 64 = 89  89 → 8² + 9² = 64 + 81 = 145  145 → 1² + 4² + 5² = 1 + 16 + 25 = 42  42 → 4² + 2² = 16 + 4 = 20  20 → 2² + 0² = 4 + 0 = 4  
The cycle repeats at 4, so the device enters an infinite loop without reaching 1. Hence, the answer is false.

Your Task
Complete the function isStableChargeCycle which takes an integer num as input, representing the initial battery level.
The function should return true if the device eventually reaches a stable state at 1, otherwise return false.

Constraints
1 ≤ num ≤ 2^31 - 1

Input Format


A single integer num representing the initial battery level of the device.



Output Format


A single line containing true if the device will eventually reach a stable charge level of 1, otherwise return false.
