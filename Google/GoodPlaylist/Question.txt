Good Playlist
Problem Statement

Alice is creating a playlist with N songs, where the duration of each song is stored in an array A.

Bob challenges Alice to find pairs of different songs that can be played together smoothly.

A pair of songs is considered good if:

Alice selects two indices i and j such that i < j (to avoid duplicate counting).

The sum of their durations is divisible by an integer K, i.e.:

(A[i] + A[j]) % K == 0

Your task is to determine the total number of such good pairs.

Input Format
The first line contains an integer N — the number of songs.
The second line contains N space-separated integers — the array A.
The third line contains an integer K.
Output Format
Print a single integer — the number of good pairs.
Constraints
1 ≤ N ≤ 10^5
1 ≤ A[i] ≤ 10^5
1 ≤ K ≤ 10^5
Example 1
Input
3
1 3 4
2
Output
1
Explanation

Possible pairs:

(1, 3) → sum = 4
(1, 4) → sum = 5
(3, 4) → sum = 7

Only 4 is divisible by 2, so there is 1 valid pair.

Example 2
Input
4
10 20 30 40
10000
Output
0
Explanation

No pair
